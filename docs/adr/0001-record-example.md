# ADR-0001: （例）バックエンドに NestJS を採用する

- ステータス: 採用
- 日付: YYYY-MM-DD

## 背景
（なぜこの判断が必要になったか）

## 決定
NestJSを採用する。

## 理由
Controller/Service/Repository + DI を強制でき、学習中のレイヤードアーキテクチャを
コードの形で体得できるため。

## 検討した代替案
- Go: システムを根っこから学べるが別言語。
- FastAPI: Python既知で新規性が低い。

## 影響
- TypeScriptでフロントと言語統一できる。
